## Convenciones de nomenclatura

- **Archivo de fuente**: `fuente-XXX-descripcion-corta.md`
- **ID de fuente**: `SRC-XXXX` o `SRC-XXXX-XXXX` para capítulos específicos
- **Tipos válidos**: `guideline`, `article`, `book`, `dataset`, `normativa`, `protocolo`, `video`, `curso`
- **Tags**: usar siempre `capítulo` + `tema principal` + `tipo`

## Checklist por fuente

- [ ] ID único asignado
- [ ] Capítulo relacionado especificado
- [ ] Tipo de fuente clasificado
- [ ] Título completo y autores
- [ ] Año de publicación/actualización
- [ ] DOI/ISBN/URL verificados
- [ ] Estado de vigencia confirmado
- [ ] Idioma indicado
- [ ] Tags asignados
- [ ] Resumen y citas relevantes escritas
- [ ] Relaciones con otros capítulos
