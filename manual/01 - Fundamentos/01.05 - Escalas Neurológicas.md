# 01.05 - Escalas Neurológicas: Glasgow, AVDI, Cincinnati, NIHSS y RASS

![[imagenes/01.05_glasgow-coma-scale.png]]

> [!abstract] Objetivo
> Aplicar las escalas neurológicas estandarizadas en el ámbito prehospitalario, reconocer sus indicaciones específicas, registrar puntuaciones de forma reproducible y utilizar el resultado para decidir el nivel de atención, el destino del paciente y la necesidad de protección avanzada de vía aérea.

---

## 1. Concepto, finalidad y principios generales

### 1.1. Definición

Las escalas neurológicas son herramientas estructuradas y validadas que permiten cuantificar el estado de conciencia, la función neurológica o el nivel de sedación de un paciente. En prehospitalaria, su finalidad no es establecer un diagnóstico definitivo, sino **objetivar la gravedad, detectar deterioro precoz y comunicar de forma homogénea** al centro receptor.

### 1.2. Principios de uso

- **Reproducibilidad:** la misma escala debe poder aplicarse por diferentes profesionales con resultados comparables.
- **Temporalidad:** deben registrarse en el momento de la valoración y volver a evaluarse ante cualquier cambio.
- **Contextualización:** la puntuación nunca se interpreta aislada; debe relacionarse con la historia clínica, el mecanismo lesional y las constantes vitales.
- **Destino:** la escala elegida debe ser la adecuada para el tipo de paciente: adulto, pediátrico, intoxicado, ictus o politraumatizado.

---

## 2. Escala de Coma de Glasgow (GCS)

### 2.1. Historia y ámbito de aplicación

La Glasgow Coma Scale (GCS) fue publicada en 1974 por Graham Teasdale y Bryan Jennett. Es la escala más utilizada worldwide para valorar el nivel de conciencia en pacientes con trauma craneoencefálico, aunque su uso se ha extendido a cualquier alteración neurológica aguda.

### 2.2. Componentes y puntuación

La GCS evalúa tres respuestas:

| Componente | Respuesta | Puntuación |
|------------|-----------|------------|
| **Apertura ocular (O)** | Espontánea | 4 |
| | Al habla | 3 |
| | Al dolor | 2 |
| | Ausente | 1 |
| **Respuesta verbal (V)** | Orientada | 5 |
| | Confusa | 4 |
| | Palabras inadecuadas | 3 |
| | Sonidos incomprensibles | 2 |
| | Ausente | 1 |
| **Respuesta motora (M)** | Obedece órdenes | 6 |
| | Localiza el dolor | 5 |
| | Retirada al dolor | 4 |
| | Flexión anormal (decorticación) | 3 |
| | Extensión anormal (descerebración) | 2 |
| | Ausente | 1 |

**Puntuación total:** 3 (coma profundo) a 15 (normal).

### 2.3. Interpretación prehospitalaria

| Puntuación | Gravedad | Actuación |
|------------|----------|-----------|
| 13-15 | Leve | Monitorizar, reevaluar, posible observación |
| 9-12 | Moderada | Traslado prioritario, valorar protección de vía aérea |
| 3-8 | Grave | Intubación orotraqueal si no protege vía aérea, traslado inmediato a centro con neurocirugía |

Un descenso de **2 o más puntos** en la GCS, incluso dentro del rango leve, indica deterioro y requiere actuación inmediata.

### 2.4. Paciente intubado o con afasia

Cuando el paciente no puede hablar por intubación orotraqueal, afasia o tracheostomía, se utiliza la escala **GCS-P** (Glasgow Coma Scale - Pupils), sustituyendo la respuesta verbal por la evaluación de las pupilas:

- **Pupilas:** simétricas y reactivas = 5; asimétricas o no reactivas = 1-3 según el hallazgo.

Esta adaptación permite seguir documentando la evolución neurológica sin perder trazabilidad.

## 3. AVDI (Airway, Voice, Grimace, Interaction)

### 3.1. Cuándo utilizarlo

El AVDI es una escala alternativa diseñada para **pacientes pediátricos** o pacientes en los que la GCS verbal es difícil de aplicar por edad o desarrollo. Evalúa cuatro componentes:

- **A - Airway / Vía aérea:** permeable o no permeable.
- **V - Voice / Voz:** llora, irritable, quieto, no responde.
- **D - Grimace / Muecas:** respuesta facial al dolor.
- **I - Interaction / Interacción:** respuesta a estímulos.

### 3.2. Puntuación

| Componente | Hallazgo | Puntuación |
|------------|----------|------------|
| Vía aérea | Permeable | 1 |
| | No permeable / obstruida | 0 |
| Voz | Llora / habla | 1 |
| | Irritable / quejido | 0 |
| Muecas | Normal / retirada al dolor | 1 |
| | Ausente | 0 |
| Interacción | Normal / alerta | 1 |
| | Disminuida / no responde | 0 |

**Puntuación total:** 0 a 4. Un AVDI bajo indica necesidad de protección avanzada de vía aérea y traslado urgente.

## 4. Escala de Cincinnati / FAST

### 4.1. Finalidad

La escala de Cincinnati, más conocida como **FAST** (Face, Arm, Speech, Time), es una herramienta de **detección precoz de ictus** diseñada para ser aplicada por personal no neurólogo en el ámbito prehospitalario.

### 4.2. Componentes

| Componente | Hallazgo positivo | Significado |
|------------|-------------------|-------------|
| **F - Face / Cara** | Asimetría facial al sonreír | Déficit motor facial central |
| **A - Arm / Brazo** | Incapacidad para mantener un brazo extendido | Hemiparesia |
| **S - Speech / Habla** | lenguaje confuso, no comprende órdenes | Afasia o disartria |
| **T - Time / Tiempo** | Cualquier hallazgo positivo | Activar código ictus y traslado inmediato |

### 4.3. Aplicación prehospitalaria

- Debe aplicarse en **menos de 2 minutos**.
- Un hallazgo positivo en cualquiera de los tres primeros componentes justifica **traslado directo a centro con capacidad de trombólisis**.
- Es fundamental registrar la **hora de inicio de los síntomas** o la última hora sin déficit, ya que define la ventana terapéutica.
- En pacientes con sordera, afasia preexistente o bajo nivel educativo, adaptar la prueba pero no descartar la sospecha.

## 5. NIHSS (National Institutes of Health Stroke Scale)

### 5.1. Finalidad

El NIHSS es una escala de **gravedad del ictus** que cuantifica el déficit neurológico en once ítems. Se utiliza principalmente en el ámbito hospitalario, pero el TES debe conocerla para:
- Comprender la valoración que recibirá el paciente en el hospital.
- Detectar cambios neurológicos durante el traslado.
- Documentar la evolución del déficit.

### 5.2. Componentes principales

| Dominio | Puntuación |
|---------|------------|
| Nivel de conciencia | 0-3 |
| Mirada conjugada | 0-2 |
| Campos visuales | 0-3 |
| Parálisis facial | 0-3 |
| Motilidad de brazo | 0-4 |
| Motilidad de pierna | 0-4 |
| Ataxia y sensibilidad | 0-2 |
| Lenguaje | 0-3 |
| Disartria | 0-2 |
| Extinción y neglect | 0-2 |

**Puntuación total:** 0 a 42.

- **0-4:** ictus leve.
- **5-15:** ictus moderado.
- **16-20:** ictus moderado-grave.
- **21-42:** ictus grave.

### 5.3. Importancia para el TES

Aunque el NIHSS no se aplica de forma completa en prehospitalaria, el TES debe reconocer que un NIHSS alto implica mayor riesgo de transformación hemorrágica, mayor dependencia postictus y necesidad de ingreso en unidad de ictus o UCI.

---

## 6. RASS (Richmond Agitation-Sedation Scale)

### 6.1. Finalidad

El RASS es una escala que mide el **nivel de agitación o sedación** del paciente. Es especialmente útil en:
- Pacientes intoxicados por sustancias depresoras o estimulantes.
- Pacientes con agitación psicomotriz.
- Pacientes sedados en ventilación mecánica.
- Reevaluación neurológica en pacientes con bajo nivel de conciencia de causa no traumática.

### 6.2. Puntuación

| Puntuación | Descripción |
|------------|-------------|
| +4 | Combativo |
| +3 | Muy agitado |
| +2 | Agitado |
| +1 | Inquieto |
| 0 | Alerta y tranquilo |
| -1 | Somnoliento |
| -2 | Sedación ligera |
| -3 | Sedación moderada |
| -4 | Sedación profunda |
| -5 | No despertable |

### 6.3. Aplicación prehospitalaria

- Permite objetivar la evolución de un paciente intoxicado o con alteración metabólica.
- Un RASS de -4 o -5 en un paciente con Glasgow bajo sugiere causa metabólica, tóxica o anóxica sobre causa estructural.
- La tendencia del RASS (mejora o empeora) es más informativa que el valor aislado.

## 7. Comparativa y algoritmo de selección

| Escala | Paciente | Finalidad | Complejidad | Entorno |
|--------|----------|-----------|-------------|---------|
| GCS | Adulto con TCE o alteración neurológica | Cuantificar nivel de conciencia | Baja | Prehospitalaria y hospitalaria |
| GCS-P | Adulto intubado | GCS adaptada | Baja | Prehospitalaria y hospitalaria |
| AVDI | Pediátrico | Nivel de conciencia en niños | Baja | Prehospitalaria |
| Cincinnati / FAST | Sospecha de ictus | Detección precoz | Muy baja | Prehospitalaria |
| NIHSS | Ictus confirmado | Gravedad y seguimiento | Alta | Hospitalaria |
| RASS | Intoxicación, sedación, agitación | Nivel de sedación/agitación | Baja | Prehospitalaria y hospitalaria |

**Regla práctica:** en prehospitalaria, el TES debe dominar GCS, AVDI y FAST. El NIHSS y el RASS son conocimientos instrumentales para entender la valoración hospitalaria y detectar cambios sutiles durante el traslado.

---

## 8. Errores críticos

- **Aplicar GCS en paciente pediátrico sin adaptar:** usar AVDI en niños pequeños o con desarrollo no compatible con la respuesta verbal adulta.
- **No registrar la puntuación inicial:** sin baseline, no es posible detectar deterioro.
- **Interpretar la GCS como diagnóstico:** una puntuación baja indica gravedad, no la causa.
- **Olvidar la hora de inicio en el ictus:** el FAST positivo sin hora de inicio no activa el protocolo de reperfusión.
- **No reevaluar:** las escalas son dinámicas; una puntuación estable en el traslado es tan informativa como una que empeora.
- **Confundir RASS con Glasgow:** miden fenómenos diferentes; un RASS -5 no equivale a un Glasgow 3.

## 9. Caso práctico

**Situación:** varón de 68 años, encontrado en el suelo por vecinos. No habla, no mueve el lado derecho. Glucemia 110 mg/dL.

1. **Apertura ocular:** al dolor → 2.
2. **Respuesta verbal:** sonidos incomprensibles → 2.
3. **Respuesta motora:** retirada al dolor en lado izquierdo, nada en derecho → 4.
4. **GCS total:** 8 (grave). Indicación de intubación si no protege vía aérea.
5. **FAST:** asimetría facial + hemiparesia derecha + lenguaje confuso → **POSITIVO**.
6. **Actuación:** intubación orotraqueal, traslado a centro con código ictus, registro de última hora sin déficit (vecinos: hace 45 minutos).

## 10. Puntos clave y checklist

- [ ] GCS: apertura ocular, respuesta verbal, respuesta motora. Total 3-15.
- [ ] GCS-P para pacientes intubados.
- [ ] AVDI para pacientes pediátricos.
- [ ] FAST para sospecha de ictus; siempre registrar hora de inicio.
- [ ] NIHSS: conocimiento instrumental para el TES.
- [ ] RASS: utilidad en intoxicaciones y agitación.
- [ ] Registrar baseline y reevaluar ante cualquier cambio.
- [ ] Un descenso de 2 o más puntos en cualquier escala es signo de deterioro.
