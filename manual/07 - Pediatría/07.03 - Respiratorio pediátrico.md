# 07.03 - Respiratorio pediátrico

> [!image-placeholder] Estridor y tiraje en patologías respiratorias pediátricas.

> [!abstract] Objetivo
> Conocer el manejo prehospitalario de las patologías respiratorias pediátricas más frecuentes: bronquiolitis, crup, epiglotitis y cuerpo extraño, aplicando oxigenoterapia y técnicas de vía aérea.

---

## 1. Bronquiolitis

### 1.1. Definición
- **Infección viral** de vías respiratorias bajas en lactantes.
- **VRS** causa principal.
- **Edad:** <2 años, pico 2-6 meses.
- **Estacional:** otoño-invierno.

### 1.2. Fisiopatología
- **Infección** epitelio bronquiolar.
- **Edema** + necrosis epitelial.
- **Hipersecreción** mucosa.
- **Broncoespasmo** + atelectasias.

### 1.3. Clínica
| Signo | Descripción |
|-------|-------------|
| **Rinorrea** | Acuosa, inicial |
| **Tos** | Seca, progresiva |
| **Sibilancias** | Espiratorias |
| **Crepitantes** | Finos |
| **Tiraje** | Intercostal, subcostal |
| **Alimentación** | Dificultosa |
| **Fiebre** | Variable |

### 1.4. Gravedad
| Grado | Clínica | Tratamiento |
|-------|---------|-------------|
| **Leve** | Tiraje leve, alimentación normal | Observación |
| **Moderado** | Tiraje moderado, alimentación dificultosa | Oxígeno, hidratación |
| **Grave** | Tiraje intenso, cianosis, fatiga | UCI |

### 1.5. Manejo
| Medida | Detalle |
|--------|---------|
| **Oxígeno** | Si SatO2 <94% |
| **Hidratación** | Cuidadosa, oral o IV |
| **Salbutamol** | Si broncoespasmo significativo |
| **Corticoides** | Teórico |
| **Transporte** | Si grave |

---

## 2. Crup (Laringotraqueobronquitis)

### 2.1. Definición
- **Inflamación** de laringe y tráquea.
- **Parainfluenza** virus principal.
- **Edad:** 6 meses - 3 años.
- **Estacional:** otoño-invierno.

### 2.2. Clínica
| Signo | Descripción |
|-------|-------------|
| **Tos** | Perruna o metálica |
| **Estridor** | Inspiratorio |
| **Tiraje** | Supraclavicular, intercostal |
| **Fiebre** | Leve-moderada |
| **Voz** | Ronca, afónica |
| **Cianosis** | En casos graves |

### 2.3. Gravedad
| Grado | Clínica | Tratamiento |
|-------|---------|-------------|
| **Leve** | Tos perruna, sin tiraje | Observación |
| **Moderado** | Estridor en reposo, tiraje | Corticoides |
| **Grave** | Cianosis, fatiga | Adrenalina nebulizada |

### 2.4. Manejo
| Medida | Detalle |
|--------|---------|
| **Oxígeno** | Humidificado |
| **Adrenalina nebulizada** | 3-5 mg si grave |
| **Corticoides** | Teórico: dexametasona |
| **Posición** | Sentado, confortable |

---

## 3. Epiglotitis

### 3.1. Definición
- **Infección** por H. influenzae tipo b.
- **Edema** de epiglotis → obstrucción alta.
- **Edad:** 2-6 años.
- **Vacuna** ha reducido incidencia.

### 3.2. Clínica
| Signo | Descripción |
|-------|-------------|
| **Fiebre alta** | Brusca, >39°C |
| **Disfagia** | Dificultad tragar |
| **Babeo** | Por disfagia |
| **Voz** | En "hot potato" |
| **Tiraje** | Importante |
| **Posición** | Tripodia |
| **Cianosis** | En casos graves |

### 3.3. Manejo
| Paso | Acción | Detalle |
|------|--------|---------|
| **1. No explorar** | Orofaringe sin vía aérea preparada | Riesgo espasmo |
| **2. Oxígeno** | Alto flujo | 15 L/min |
| **3. Transporte** | Urgente a hospital | UCI |
| **4. Preparar** | Intubación o cirugía | Material listo |

---

## 4. Cuerpo Extraño

### 4.1. Clínica
| Signo | Descripción |
|-------|-------------|
| **Tos** | Súbita, ahogo |
| **Estridor** | Obstrucción alta |
| **Sibilancias** | Obstrucción baja |
| **Incapacidad** | Hablar/llorar si obstrucción completa |
| **Cianosis** | Por obstrucción |

### 4.2. Manejo
| Situación | Acción |
|-----------|--------|
| **Obstrucción completa** | Maniobras de desobstrucción |
| **Obstrucción parcial** | Oxígeno, transporte urgente |
| **No** | Realizar exploración ciega |

### 4.3. Localización
| Localización | Clínica |
|--------------|---------|
| **Alta** | Estridor, tos, ahogo |
| **Baja** | Sibilancias, taquipnea |
| **Esófago** | Salivación, disfagia |

---

## 5. Comparación Patologías

### 5.1. Características
| Patología | Tos | Estridor | Fiebre | Edad |
|-----------|-----|----------|--------|------|
| **Bronquiolitis** | Seca | No | Variable | <2 años |
| **Crup** | Perruna | Inspiratorio | Leve | 6m-3a |
| **Epiglotitis** | No | Inspiratorio | Alta | 2-6 años |
| **Cuerpo extraño** | Súbita | Variable | No | Cualquier |

### 5.2. Diagnóstico diferencial
| Diagnóstico | Clave |
|-------------|-------|
| **Bronquiolitis** | VRS, tiraje, sibilancias |
| **Crup** | Tos perruna + estridor |
| **Epiglotitis** | Fiebre alta + babeo + tripodia |
| **Cuerpo extraño** | Tos súbita + ahogo |

---

## 6. Manejo de Vía Aérea

### 6.1. Posiciones
| Situación | Posición |
|-----------|----------|
| **Distress leve** | Semiincorporado |
| **Distress moderado** | Sentado |
| **Obstrucción alta** | Tripodia |
| **Fatiga** | Lateral de seguridad |

### 6.2. Oxigenoterapia
| Situación | Flujo | Método |
|-----------|-------|--------|
| **Leve** | 5-10 L/min | Mascarilla simple |
| **Moderado** | 10-15 L/min | Mascarilla con reservorio |
| **Grave** | 15 L/min | Mascarilla no reinhalación |
| **Humidificado** | 10-15 L/min | Cámara de humidificación |

### 6.3. Técnicas
| Técnica | Indicación |
|---------|------------|
| **Aspiración** | Secretiones, cuerpo extraño |
| **Maniobras desobstrucción** | Obstrucción completa |
| **Ventilación bolsa** | Parada respiratoria |
| **Intubación** | Fracaso ventilación |

---

## 7. Complicaciones

### 7.1. Inmediatas
| Complicación | Causa | Prevención |
|--------------|-------|------------|
| **Parada respiratoria** | Obstrucción completa | Desobstrucción precoz |
| **Neumotórax** | Barotrauma | Ventilación suave |
| **Aspiración** | Cuerpo extraño | Posición lateral |
| **Hipoxia** | Obstrucción vía aérea | Oxígeno precoz |

### 7.2. Tardías
- **Secuelas neurológicas:** hipoxia prolongada.
- **Bronquiectasias:** infección repetida.
- **Asma:** historia respiratoria.

## 8. Criterios de Destino

### 8.1. Urgencia
| Hallazgo | Destino |
|----------|---------|
| **Epiglotitis** | UCI |
| **Cuerpo extraño obstrucción** | UCI/cirugía |
| **Crup grave** | UCI |
| **Bronquiolitis grave** | UCI |

### 8.2. Observación
| Hallazgo | Destino |
|----------|---------|
| **Crup leve** | Observación |
| **Bronquiolitis leve** | Alta con seguimiento |
| **Cuerpo extraño extraído** | Observación |

## 9. Caso Práctico

> [!example] 
> **Situación:** Niño de 2 años, tos perruna desde hace 2 días. Ahora estridor en reposo, tiraje intenso, cianosis.
> 
> **Hallazgos:**
> - Consciente, irritable.
> - TA: 90/60 mmHg, FC: 140 lpm.
> - FR: 50 rpm.
> - SatO2: 92% con aire ambiente.
> - Estridor inspiratorio.
> - Tiraje supraclavicular.
> 
> **Manejo:**
> 1. **Posición:** sentado, confortable.
> 2. **Oxígeno:** 15 L/min.
> 3. **Adrenalina nebulizada:** 3-5 mg.
> 4. **Corticoides:** teórico.
> 5. **Monitorizar:** ECG, TA, SatO2.
> 6. **Transporte** urgente a UCI.
> 7. **Informar:** crup grave, estridor en reposo.

## 11. Checklist de Repaso

- [ ] Identificar patrón respiratorio: bronquiolitis, crup, epiglotitis, cuerpo extraño
- [ ] Valorar gravedad: tiraje, cianosis, fatiga
- [ ] Administrar oxígeno humidificado
- [ ] Posicionar según patología
- [ ] Adrenalina nebulizada en crup grave
- [ ] NO explorar epiglotitis sin vía aérea preparada
- [ ] Aspirar secreciones si necesario
- [ ] Preparar maniobras desobstrucción si cuerpo extraño
- [ ] Monitorizar FC, FR, SatO2
- [ ] Transporte urgente según gravedad
- [ ] Informar sobre patología sospechada
