# 07.11 - RN crítico avanzado

> [!image-placeholder] RN crítico avanzado con prematuridad extrema y hernia diafragmática.

> [!abstract] Objetivo
> Conocer el manejo prehospitalario avanzado del recién nacido crítico: prematuridad extrema, shock neonatal, infección y hernias diafragmáticas complejas.

---

## 1. Prematuridad Extrema

### 1.1. Definición
- **RN extremadamente pretérmino:** <28 semanas.
- **Muy bajo peso:** <1500 g.
- **Muy extremo:** <32 semanas.
- **Extremo:** <28 semanas.
- **Inmadurez:** múltiples sistemas.

### 1.2. Riesgos
| Sistema | Riesgo |
|---------|--------|
| **Pulmonar** | Síndrome distress respiratorio |
| **Neurológico** | Hemorragia intraventricular |
| **Cardiovascular** | Inestabilidad hemodinámica |
| **Térmico** | Hipotermia extrema |
| **Infeccioso** | Sepsis neonatal |

### 1.3. Manejo
| Paso | Acción | Detalle |
|------|--------|---------|
| **1. Calentar** | Inmediatamente | Manta térmica, <28°C ambiente |
| **2. Humidificar** | Oxígeno | Prevenir sequedad |
| **3. Posición** | Neutra, cabeza media | Vía aérea permeable |
| **4. Oxígeno** | Controlado | SatO2 90-95% |
| **5. Ventilación** | Suave | Evitar barotrauma |
| **6. Monitorizar** | FC, FR, SatO2, temperatura | Detectar deterioro |

---

## 2. Shock Neonatal

### 2.1. Definición
- **Hipoperfusión tisular** grave.
- **TA:** TAS <60 mmHg.
- **FC:** <100 o >160 lpm.
- **Pulso:** débil, filiforme.

### 2.2. Causas
| Tipo | Causa | Ejemplo |
|------|-------|---------|
| **Hipovolémico** | Pérdida líquidos | Hemorragia, deshidratación |
| **Séptico** | Infección | Bacteriemia, meningitis |
| **Cardiogénico** | Fallo cardíaco | Miocarditis, cardiopatía |
| **Obstructivo** | Obstrucción | Hernia diafragmática |

### 2.3. Clínica
| Signo | Descripción |
|-------|-------------|
| **Palidez, cianosis** | Piel gris, moteada |
| **Hipotensión** | TAS <60 mmHg |
| **Taquicardia** | FC >160 lpm |
| **Bradicardia** | FC <100 lpm |
| **Disminución pulso** | Débil, filiforme |
| **Alteración conciencia** | Letargo, coma |
| **Oligoanuria** | Diuresis <1 mL/kg/h |

### 2.4. Manejo
| Paso | Acción | Detalle |
|------|--------|---------|
| **1. Vía aérea** | Permeable | Aspiración |
| **2. Oxígeno** | Alto flujo | 15 L/min |
| **3. Vía IV/IO** | Acceso inmediato | IO si no IV en <90 s |
| **4. Fluidoterapia** | 20 mL/kg SF 0.9% | En 5-10 min |
| **5. Repetir** | Si no mejora | Hasta 3 bolos |
| **6. Monitorizar** | ECG, TA, SatO2 | Detectar respuesta |

---

## 3. Infección Neonatal

### 3.1. Definición
- **Infección** en primeros 28 días.
- **Sepsis neonatal** = mortalidad alta.
- **Transmisión:** vertical, horizontal.
- **Patógenos:** S. agalactiae, E. coli, L. monocytogenes.

### 3.2. Clínica
| Signo | Descripción |
|-------|-------------|
| **Fiebre** | >38°C o hipotermia <36°C |
| **Letargo** | Somnolencia, hipotonía |
| **Irritabilidad** | Llanto inconsolable |
| **Dificultad alimentación** | Succión débil |
| **Respiración alterada** | Taquipnea, apnea |
| **Hipotensión** | Shock |
| **Ictericia** | Precoz, intensa |
| **Púrpura** | Petequias, equimosis |

### 3.3. Manejo
| Paso | Acción | Detalle |
|------|--------|---------|
| **1. Aislamiento** | Precauciones estándar | Contacto |
| **2. Vía aérea** | Permeable | Aspiración |
| **3. Oxígeno** | Alto flujo | 15 L/min |
| **4. Vía IV** | Acceso | Si shock |
| **5. Fluidoterapia** | SF 0.9% | En shock |
| **6. Antibióticos** | Teórico | Ceftriaxona + gentamicina |
| **7. Transporte** | Urgente a UCI | Neonatal |

---

## 4. Hernia Diafragmática Congénita

### 4.1. Definición
- **Defecto** diafragmático → herniación abdominal a tórax.
- **Compresión** pulmonar grave.
- **Asociada** a otras malformaciones.
- **Mortalidad** alta sin tratamiento precoz.

### 4.2. Clínica
| Signo | Descripción |
|-------|-------------|
| **Distress respiratorio** | Grave desde nacimiento |
| **Cianosis** | No mejora con oxígeno |
| **Tórax** | Asimétrico, timpánico |
| **Abdomen** | Escafoides |
| **Ruidos** | Cardíacos desplazados |
| **Ausencia** ruido respiratorio | Lado hernia |

### 4.3. Manejo
| Paso | Acción | Detalle |
|------|--------|---------|
| **1. Vía aérea** | Permeable | Intubación precoz |
| **2. Oxígeno** | Alto flujo | 15 L/min |
| **3. Ventilación** | Suave | Evitar barotrauma |
| **4. Sonda** | Nasogástrica | Descompresión gástrica |
| **5. Posición** | Decúbito lateral | Mejorar ventilación |
| **6. Transporte** | Urgente a cirugía | UCI neonatal |

---

## 5. Otras Patologías

### 5.1. Enfermedad membrana hialina
- **Deficiencia** surfactante.
- **RN pretérmino** <32 semanas.
- **Distress respiratorio** progresivo.
- **Ventilación** con PEEP.

### 5.2. Taquipnea transitoria
- **Autolimitada** <72 h.
- **RN** a término o postérmino.
- **Taquipnea** sin distress grave.
- **Observación** y apoyo.

### 5.3. Sepsis neonatal precoz
- **Primeros** 7 días.
- **Madre** factores riesgo: fiebre, colonización.
- **Clínica:** inespecífica.
- **Tratamiento:** antibióticos precoz.

---

## 6. Complicaciones

### 6.1. Inmediatas
| Complicación | Causa | Prevención |
|--------------|-------|------------|
| **Hipotermia** | Exposición | Calentar precoz |
| **Hipoxia** | Inmadurez, obstrucción | Oxígeno, ventilación |
| **Neumotórax** | Barotrauma | Ventilación suave |
| **Hemorragia intraventricular** | Fragilidad vascular | Manejo suave |
| **Sepsis** | Inmunidad baja | Aislamiento, antibióticos |

### 6.2. Tardías
- **Displasia broncopulmonar:** ventilación prolongada.
- **Retinopatía:** oxígeno alto.
- **Parálisis cerebral:** hipoxia prolongada.
- **Hernia diafragmática:** recurrencia.

---

## 7. Criterios de Destino

### 7.1. Urgencia
| Hallazgo | Destino |
|----------|---------|
| **Prematurez extrema** | UCI neonatal nivel III |
| **Shock neonatal** | UCI neonatal |
| **Sepsis** | UCI neonatal |
| **Hernia diafragmática** | UCI neonatal/cirugía |
| **Distress respiratorio** | UCI neonatal |

### 7.2. Información al hospital
- Edad gestacional, peso.
- Líquido amniótico: claro/meconio.
- Tiempo reanimación.
- Fármacos administrados.
- Evolución FC, SatO2.

---

## 8. Caso Práctico

> [!example] 
> **Situación:** RN de 26 semanas, 800 g. Distress respiratorio grave, cianosis, FC 180 lpm.
> 
> **Hallazdos:**
> - RN extremadamente pretérmino.
> - Peso 800 g.
> - Cianosis, tiraje intenso.
> - FC: 180 lpm, FR: 80 rpm.
> - SatO2: 80% con aire ambiente.
> - Hipotermia 35.8°C.
> 
> **Manejo:**
> 1. **Calentar:** manta térmica, gorrito.
> 2. **Posición:** decúbito supino, cuello extendido.
> 3. **Oxígeno:** 15 L/min, humidificado.
> 4. **Ventilación:** BVM suave, 40-60 rpm.
> 5. **Sonda:** nasogástrica descompresión.
> 6. **Vía IO:** acceso tibial.
> 7. **Monitorizar:** FC, SatO2, FR, temperatura.
> 8. **Transporte** a UCI neonatal nivel III.
> 9. **Informar:** pretérmino 26 semanas, distress respiratorio.

## 10. Checklist de Repaso

- [ ] Calentar RN extremadamente pretérmino
- [ ] Evaluar edad gestacional y peso
- [ ] Valorar líquido amniótico: claro/meconio
- [ ] Aspirar boca y nariz si secreciones
- [ ] Ventilar si no respira o FC <100
- [ ] Oxígeno controlado en prematurez
- [ ] Humidificar oxígeno
- [ ] Sonda nasogástrica si hernia diafragmática
- [ ] Intubar precozmente si hernia diafragmática
- [ ] Monitorizar FC, FR, SatO2, temperatura
- [ ] Fluidoterapia 20 mL/kg en shock
- [ ] Vía IO si no hay vía periférica
- [ ] Antibióticos teóricos en sepsis
- [ ] Transporte a UCI neonatal nivel III
- [ ] Informar: edad gestacional, peso, tratamiento
